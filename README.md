# RishMacOSTools

RishMacOSTools is a macOS app for simple SSH management.

It helps you:
- manage SSH keys
- manage SSH servers in `~/.ssh/config`
- quickly copy public keys and helper commands
- connect to servers from your preferred terminal
- clean `known_hosts` entries (globally or per selected server)

## Requirements

- macOS 14.6+
- system OpenSSH tools (`ssh`, `ssh-keygen`, `ssh-add`)
- read/write access to your `~/.ssh` folder
